# TechNova Services

Site vitrine **fictif** de dépannage informatique situé à Bruxelles, conçu pour un exercice scolaire SEO/GEO. Aucun service réel, aucune adresse commerciale et aucune collecte de données.

## Pages
- `index.html` — Accueil
- `services.html` — Six services fictifs, recherche et filtres JavaScript, FAQ
- `apropos.html` — Présentation, résumé GEO
- `contact.html` — Formulaire de simulation sans envoi

## Référencement
- `sitemap.xml` — 4 adresses canoniques
- `robots.txt` — Exploration autorisée et lien vers le sitemap
- JSON-LD Schema.org sur chaque page (`Organization`, `WebSite`, pages, liste des services)
- Métadonnées, descriptions et URL canonical
- `llms.txt` — fichier informatif facultatif, sans efficacité garantie
